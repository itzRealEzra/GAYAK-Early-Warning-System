GAYAK LOCAL DASHBOARD

Setup & Installation

Prepare the Windows dashboard, install its Python packages, and connect the Arduino over USB.

Back To Dashboard

1. Download The Project

Download and extract the repository. Keep install_gayak.bat, start_gayak.bat, and requirements.txt together in the project folder.

Download Project ZIP View GitHub Repository

2. Install Python

Install Python 3 for Windows if it is not already installed. The installer uses the Python launcher (py) when available, or python as a fallback.

Download Python From Python.org

Arduino IDE Libraries

In Arduino IDE Library Manager, install DHT sensor library by Adafruit, Adafruit Unified Sensor, and a compatible LiquidCrystal_I2C library. Wire is included with the Arduino Uno core.

3. Install Dashboard Packages

  1. Open the extracted project folder.
  2. Double-click install_gayak.bat.
  3. Allow it to download Flask and PySerial. This needs an internet connection the first time.

The installer creates a project-local .venv, so the dashboard packages stay separate from other Python projects.

4. Connect And Launch

  1. Upload the physical sketch arduino/GAYAK.ino to the Arduino.
  2. Connect the Arduino to the PC with USB.
  3. Close Arduino Serial Monitor and Serial Plotter so the dashboard can use the COM port.
  4. Double-click start_gayak.bat. It installs missing packages if needed and opens the dashboard.

Open http://127.0.0.1:5000 if the browser does not open automatically. Keep the console window open while using the dashboard; press Ctrl + C in that window to stop it.

Choose The Arduino COM Port

The dashboard tries to find the Arduino automatically. If it selects the wrong port, open Command Prompt in the project folder and run:

set GAYAK_COM_PORT=COM4
start_gayak.bat

Replace COM4 with the Arduino's port in Windows Device Manager. The dashboard listens only on this PC at 127.0.0.1.
