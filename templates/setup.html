GAYAK LOCAL DASHBOARD

Dashboard Setup

Install the dashboard on a Windows PC and connect your already-programmed Arduino to view live sensor readings.

Back To Dashboard

What You Need

  • A Windows 10 or 11 PC
  • The assembled GAYAK Arduino with firmware already uploaded
  • A USB data cable and Python 3 for Windows
  • This project downloaded to the PC

Arduino IDE is not needed to run the dashboard. The Arduino must remain connected and powered for live sensor readings.

1. Download The Project

Download and extract the project ZIP. Keep the files together in the extracted folder.

Download Project ZIP View GitHub Repository

2. Install Python And Dashboard Packages

  1. If Python 3 is not installed, download it for Windows. Enable the option to add Python to PATH if offered.
  2. Open the extracted project folder and double-click install_gayak.bat.
  3. Allow the script to download Flask and PySerial. Internet access is needed for the initial setup.

The installer creates a project-local .venv; it does not install dashboard packages system-wide.

3. Connect The Arduino And Start

  1. Connect the already-programmed Arduino to the PC with a USB data cable and power it on.
  2. Close Arduino Serial Monitor, Serial Plotter, or other serial terminal apps if open; only one app can use the COM port at a time.
  3. Double-click start_gayak.bat.
  4. If the browser does not open automatically, visit http://127.0.0.1:5000.

Keep the command window open while using the dashboard. Press Ctrl + C there to stop the server. The dashboard runs locally and does not require Wi-Fi or a database.

4. Check Live Readings

  • Confirm the dashboard's System, Arduino USB, and Live Feed indicators connect.
  • After power-up, the Arduino runs the MQ-2 warm-up and clean-air baseline (about 2 minutes 20 seconds). The dashboard displays the Arduino's sensor data; it does not perform sensor calibration.
  • Confirm temperature, humidity, HI, gas/smoke, flame, and MPU-6050 readings update.

If The Arduino Is Not Detected

The dashboard tries to select the Arduino automatically. If needed, find its COM port in Windows Device Manager and run this from Command Prompt in the project folder:

set GAYAK_COM_PORT=COM4
start_gayak.bat

Replace COM4 with the actual port. Check that the cable supports data and that no other program is using the port.

Changing The Arduino Firmware

This is only needed if you want to modify or re-upload the Arduino code. A developer can use Arduino IDE and the firmware and hardware tutorial. The dashboard client does not need to install Arduino IDE.
