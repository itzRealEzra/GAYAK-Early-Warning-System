Complete Setup & Installation

Build and wire the prototype, upload the Arduino firmware, install the dashboard, and connect it over USB.

1. Download The Project

Download and extract the repository. Keep install_gayak.bat, start_gayak.bat, and requirements.txt together in the project folder.

Download Project ZIP View GitHub Repository

2. Install Arduino IDE

Download and install Arduino IDE for Windows. You will use it to install firmware libraries and upload the project sketch.

Download Arduino IDE · Official Install Instructions

3. Wire The Hardware

Gather an Uno, DHT22, MQ-2 (AO), digital flame module (DO), GY-521/MPU-6050, 16×2 I2C LCD, three LEDs, D11 pushbutton, three active buzzers, suitable buzzer drivers, jumper wires, and a breadboard/perfboard.

Use USB power for first tests. Connect grounds together and check each module's supply voltage. See the full wiring and power guide before assembly.

Uno PinConnection
D2DHT22 DATA
D3Flame sensor DO
A0MQ-2 AO
A4 / A5LCD and GY-521 shared SDA / SCL
D5 / D6 / D7Green / yellow / red LEDs, each with its own 220Ω resistor
D8 / D9 / D10Smoke / shaking / fire buzzer driver inputs
D11Pushbutton to GND (`INPUT_PULLUP`)

Do not connect physical active buzzers directly to Arduino GPIO. Use appropriately rated transistor/MOSFET driver circuits. Leave the 18650/TP4056 battery disconnected during initial USB tests.

A bare DHT22 may need a data pull-up resistor; some sensor boards include one. Check LCD backpack pull-ups against GY-521 I2C voltage limits and use level shifting as needed.

4. Set Up Arduino IDE

  1. If needed, install the Arduino AVR Boards package from Tools → Board → Boards Manager. See the board package guide.
  2. In Tools → Manage Libraries, install DHT sensor library by Adafruit, Adafruit Unified Sensor, and a compatible LiquidCrystal_I2C library. Wire is included with the Uno core.
  3. Open arduino/GAYAK/GAYAK.ino, select Tools → Board → Arduino Uno, then select the Arduino's COM port from Tools → Port.
  4. During startup, aim the flame module at a normal indoor scene so firmware can learn its idle state. Keep MQ-2 in clean air for baseline calibration, then click Upload.
  5. Optionally open Serial Monitor at 115200 baud to confirm readings. Close Serial Monitor before running the dashboard.

The physical MQ-2 uses a 2-minute warm-up and a 20-second clean-air baseline. Let the flame module learn its normal indoor idle state at boot. Use Wokwi or benign bench inputs for testing; do not create smoke or flame indoors.

5. Install Python And Dashboard Packages

  1. Install Python 3 for Windows if it is not already installed.
  2. From the extracted project folder, double-click install_gayak.bat.
  3. Allow the script to download Flask and PySerial. Internet is needed for the first install.

The script creates a project-local .venv and installs packages there, separate from other Python projects.

Download Python From Python.org

6. Connect And Launch

  1. Connect the uploaded Arduino to the PC with a USB data cable.
  2. Close Arduino Serial Monitor and Serial Plotter; only one program can use the COM port at a time.
  3. Double-click start_gayak.bat. It checks the project environment and opens the dashboard.

Open http://127.0.0.1:5000 if the browser does not open automatically. Keep the console window open while using the dashboard; press Ctrl + C there to stop the server. The page is local to this PC; it does not need Wi-Fi or a database.

7. Confirm The First Run

  • Check that the dashboard's System, Arduino USB, and Live Feed indicators connect.
  • Let MQ-2 finish its 2-minute warm-up and 20-second clean-air baseline.
  • Confirm temperature, humidity, HI, gas/smoke, flame, and MPU-6050 readings appear.
  • Use Wokwi or benign bench inputs for alarm checks. Do not make smoke or a flame to test the prototype.

Choose The Arduino COM Port

The dashboard tries to find the Arduino automatically. If it selects the wrong port, open Command Prompt in the project folder and run:

set GAYAK_COM_PORT=COM4
start_gayak.bat

Replace COM4 with the Arduino's port in Windows Device Manager. The dashboard listens only on this PC at 127.0.0.1.
